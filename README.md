**A full-stack web application for managing gym operations: members, subscriptions, schedules, payments, and coaches.**

FitManager is a practical fitness center management system built with modern web technologies. This project demonstrates full-stack development skills (PHP backend, MySQL database, HTML/CSS/JS frontend) and is part of my portfolio showcasing programming beyond cybersecurity.

Perfect for small to medium gyms looking for an affordable, customizable management tool.

## 🚀 Features
- Member registration and profile management
- Subscription plans and automated payment tracking
- Class/instructor scheduling
- Attendance tracking
- Coach and staff management
- Dashboard with stats (active members, revenue, etc.)
- Responsive design for desktop and mobile

## 🛠️ Technologies Used
- **Backend**: PHP
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap (for responsive UI)
- **Database**: MySQL
- **Optional**: Apache/Nginx server setup
